# The World Today — 18 November 2026 in one image

Entry for the make.fun bounty "Sum up 18 November's world news in one image"
(`news-image-20261118`).

`main.ts` (Node 22, standard library only) copies `entry.png` — a front page
summarising the day's world news — to `/output/entry.png`. The image is drawn
from real reporting of Wednesday 18 November 2026: the U.S.–Iran escalation
in the Gulf, Ukraine's second-night strike on the Kerch Bridge, the Xi–Putin–
Trump meeting in Shenzhen, Peltola's Alaska Senate win, Gaza's winter warning,
COP31, the Ebola surge in DR Congo, and the day's other top stories.

Run locally: `mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts`
